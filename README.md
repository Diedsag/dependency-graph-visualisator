# Визуализатор графа зависимостей (Вариант 26)

## Общее описание
CLI-инструмент для анализа и визуализации графа зависимостей пакетов (npm). 
Приложение поддерживает обход в ширину (BFS), ограничение глубины анализа, 
обработку циклов и вывод результатов в форматах Graphviz и ASCII-дерева.

## Функции и настройки
Параметры передаются через аргументы командной строки:
- `--package`: Имя анализируемого пакета (обязательный).
- `--source`: URL репозитория или путь к файлу тестового репозитория.
- `--test-mode`: Флаг включения режима работы с локальным тестовым графом.
- `--ascii-tree`: Флаг вывода зависимостей в виде ASCII-дерева.
- `--max-depth`: Максимальная глубина анализа (по умолчанию -1, без ограничений).
