# Визуализатор графа зависимостей (Вариант 26)

## Общее описание

Инструмент командной строки для анализа графа
зависимостей пакетов менеджера **npm**.

Приложение строит граф зависимостей с учётом
транзитивности, используя алгоритм обхода в ширину
(**BFS**) без рекурсии. Поддерживаются:

- Ограничение максимальной глубины анализа.
- Корректная обработка циклических зависимостей.
- Тестовый режим с локальным файлом-описанием графа.

Данные о зависимостях извлекаются напрямую из
реестра `registry.npmjs.org` через встроенную
библиотеку `urllib` (без использования пакетных
менеджеров и сторонних библиотек).

## Описание функций и настроек

### Параметры командной строки

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|---|---|---|---|---|
| `--package` | строка | да | — | Имя анализируемого пакета |
| `--source` | строка | да | — | URL репозитория или путь к файлу тестового репозитория |
| `--test-mode` | флаг | нет | `false` | Режим работы с тестовым репозиторием |
| `--ascii-tree` | флаг | нет | `false` | Вывод зависимостей в формате ASCII-дерева |
| `--max-depth` | целое число | нет | `-1` | Максимальная глубина анализа. `-1` — без ограничений |

### Валидация параметров

Все входные параметры проходят строгую валидацию
перед началом работы:

- **`--package`**: проверяется регулярным выражением
  `^[a-z0-9@\/._-]+$` (регистронезависимо).
  Пустые значения и недопустимые символы отклоняются.
- **`--source`**: в обычном режиме проверяется
  как URL (`http://` или `https://`). В режиме
  `--test-mode` проверяется как путь к файлу
  с расширением. Пустые значения отклоняются.
- **`--max-depth`**: должно быть целым числом
  не меньше `-1`. Нецелые значения отклоняются
  парсером `argparse` автоматически.

При обнаружении ошибки приложение выводит
сообщение об ошибке и завершается с кодом
возврата `1`. При ошибках `argparse` (например,
отсутствие обязательного параметра) выводится
справка и код возврата `2`.

### Режим тестового репозитория

При активации флага `--test-mode` параметр
`--source` интерпретируется как путь к
локальному JSON-файлу, описывающему граф
зависимостей. Пакеты в файле называются
большими латинскими буквами.

Формат тестового файла:

```json
{
    "A": {"dependencies": {"B": "1.0", "C": "1.0"}},
    "B": {"dependencies": {"D": "1.0"}},
    "C": {"dependencies": {"D": "1.0", "E": "1.0"}},
    "D": {"dependencies": {}},
    "E": {"dependencies": {"A": "1.0"}}
}
