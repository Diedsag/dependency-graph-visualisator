# Визуализатор графа зависимостей (Вариант 26)

## Общее описание

CLI-инструмент для анализа графа зависимостей пакетов npm.
Приложение получает данные из реестра через встроенный `urllib`,
строит граф обходом в ширину (BFS) без рекурсии, учитывает
максимальную глубину и циклические зависимости.

## Функции и настройки

Параметры командной строки:

| Параметр | Тип | Обязательный | Значение | Описание |
|---|---|---|---|---|
| `--package` | строка | да | — | Имя пакета для анализа |
| `--source` | строка | да | — | URL репозитория или путь к тестовому файлу |
| `--test-mode` | флаг | нет | false | Использовать локальный тестовый репозиторий |
| `--ascii-tree` | флаг | нет | false | Вывод зависимостей в виде ASCII-дерева |
| `--max-depth` | число | нет | -1 | Максимальная глубина, -1 без ограничений |
| `--reverse-for` | строка | нет | — | Пакет для поиска обратных зависимостей |

Валидация:

- `--package` и `--reverse-for` проверяются регулярным выражением
  `^[a-z0-9@\/._-]+$` без учета регистра.
- `--source` в обычном режиме проверяется как URL `http://` или
  `https://`, в тестовом режиме — как путь к файлу с расширением.
- `--max-depth` должно быть целым числом не меньше `-1`.
- Ошибки конфигурации выводятся без трейсбека и возвращают код `1`.

Логика работы:

- `NpmFetcher` получает JSON пакета из npm и возвращает прямые
  зависимости.
- `TestFetcher` читает тот же формат из локального JSON-файла.
- `GraphBuilder` строит граф алгоритмом BFS через `collections.deque`.
- `Graph` хранит списки смежности и умеет искать обратные зависимости
  через инвертированный BFS.

## Сборка и запуск

Проект не требует сборки. Требуется Python 3.10+
и установленный `pytest`.

Запуск из корня:

```bat
run.bat
```

Ручной запуск:

```bat
python -m src.main --package express --source https://registry.npmjs.org --max-depth 2
```

Тесты:

```bat
pytest tests
```

## Тестовый репозиторий

Для `--test-mode` используется `test_graph.json`:

```json
{
  "A": {"dependencies": {"B": "1.0", "C": "1.0"}},
  "B": {"dependencies": {"D": "1.0"}},
  "C": {"dependencies": {"D": "1.0", "E": "1.0"}},
  "D": {"dependencies": {}},
  "E": {"dependencies": {"A": "1.0"}}
}
```

Пакеты обозначаются большими латинскими буквами.

## Примеры использования

Полный обход:

```bat
python -m src.main --package A --source test_graph.json --test-mode
```

Глубина 1:

```bat
python -m src.main --package A --source test_graph.json --test-mode --max-depth 1
```

Обратные зависимости D:

```bat
python -m src.main --package A --source test_graph.json --test-mode --reverse-for D
```

Ожидаемый результат: A, B, C, E.

Ошибочный ввод:

```bat
python -m src.main --package "BAD NAME!" --source https://registry.npmjs.org
```

Ожидаемый результат: сообщение об ошибке имени пакета.
